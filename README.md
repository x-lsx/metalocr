# METAL — распознавание маркировки металла

Минимальная версия для проверки готовой OCR-модели на одном фото или папке.
Находит текст, выбирает поворот, отбрасывает штамп даты камеры и извлекает
номер плавки. Результаты сохраняются в CSV и JSON.

Веса детектора и дообученного распознавателя включены — около 96 МБ.
После установки зависимостей скачивание моделей не требуется.
Для установки Python-пакетов нужен интернет либо заранее подготовленные wheels.

## Установка и запуск

Python 3.12, 64 bit. Команды выполняются из корня проекта.
Замените путь к фотографии на свой. Поддерживаются JPG, JPEG и PNG.

### CPU, Windows PowerShell

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe recognize.py "C:\photos\photo.jpg" --config config.final.cpu.json --out results
```

### CPU, Linux

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python recognize.py /path/to/photo.jpg --config config.final.cpu.json --out results
```

На машине разработки один проверочный запуск фото на CPU, включая загрузку
моделей, занял около 162 секунд. Для быстрой демонстрации используйте GPU.

### NVIDIA GPU

Используйте отдельное окружение с GPU-сборкой Paddle:

```powershell
py -3.12 -m venv .venv-gpu
.\.venv-gpu\Scripts\python.exe -m pip install -r requirements.gpu.txt
.\.venv-gpu\Scripts\python.exe recognize.py "C:\photos\photo.jpg" --config config.final.gpu.json --out results
```

Проверенная конфигурация: Windows, Python 3.12, Paddle GPU 3.3.1,
NVIDIA RTX 3050 Laptop 4 ГБ. GPU-сборка Paddle и драйвер NVIDIA должны быть
совместимы; доступные сборки перечислены в
[инструкции PaddlePaddle](https://www.paddlepaddle.org.cn/install/quick).
CPU- и GPU-дистрибутивы Paddle устанавливаются в разные окружения.
В уже подготовленном локальном окружении `venv` повторная установка не нужна.

Для папки фотографий передайте путь к папке вместо пути к файлу:

```powershell
.\.venv-gpu\Scripts\python.exe recognize.py "C:\photos" --config config.final.gpu.json --out results
```

Для CPU используйте `.venv` и `config.final.cpu.json`.
Обрабатываются файлы непосредственно в указанной папке. Первый кадр включает
загрузку моделей в память и обрабатывается дольше следующих.

Минимальный набор проверен на CPU и GPU с пустым кэшем PaddleX и запрещёнными
сетевыми подключениями: оба запуска распознали контрольный номер `V30593`,
обращений в сеть не было. Проверка выполнена в установленном окружении
разработчика, установка зависимостей с нуля отдельно не проверялась.

## Результаты

- `results/results.csv`: файл, текст, `heat_id` (плавка без года), `heat_year`,
  уверенность, поворот, статус и время.
- `results/<имя фото>.json`: подробный результат с координатами строк.

Статусы: `ok`, `low_confidence`, `not_found`, `error`. `ok` означает прохождение
порога уверенности, а не гарантию правильности текста. Если год не напечатан,
он не восстанавливается из имени файла. Ошибка отдельного фото записывается
в поле `error` и не останавливает пакет.

## Файлы

```text
metalocr/                             код обработки и распознавания
recognize.py                          запуск одного фото или папки
config.json                           базовые настройки
config.final.gpu.json                 финальная модель, GPU
config.final.cpu.json                 та же модель, CPU
requirements.txt                      зависимости CPU
requirements.gpu.txt                  зависимости GPU
models/PP-OCRv5_server_det/            детектор текста
models/metal_rec_expand_20261117/
  inference/                          дообученный распознаватель
models/LICENSE                        лицензия PaddleOCR
models/NOTICE.md                      происхождение моделей
```

В каждой модели нужны все три файла: `inference.json`, `inference.pdiparams`,
`inference.yml`. Пути задаются относительно корня проекта. `config.json`
загружается всегда; финальный конфиг дополняет его выбранными моделями.

Фотографии передаются своим путём. Исходный датасет, разметка, веб-редактор,
обучающие кропы, обучение и прошлые эксперименты в минимальный репозиторий
не входят. Для распознавания эталоны не нужны; для расчёта точности требуется
отдельная проверенная разметка и оценочный скрипт.

## Результат разработки

Модель обучена на 405 Train-фото / 1214 кропах, 30 эпох; выбрана 21-я эпоха.
На 100 проверенных фото Validation 24 нечитаемых исключены. На остальных
76 фото номер плавки **без года**:

| Метрика | Результат |
|---|---:|
| Exact Match | 61/76 — 80,26% |
| CER номера | 15,70% |
| Верный поворот | 67/76 — 88,16% |
| Среднее время на RTX 3050 | 3,17 с/читаемое фото |

Это Validation, а не приёмка на всех 436 Test. Время на CPU этим замером
не подтверждено. Чтение номера улучшилось относительно предыдущей модели,
но год и вспомогательный текст стали хуже: год 22/28 вместо 23/28;
CER всего текста на 33 полностью размеченных фото — 45,21% вместо 36,57%.
Метрики номера не характеризуют точность всего текста маркировки.
