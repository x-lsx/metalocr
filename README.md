# METAL OCR — плавка и номер листа

Локальное приложение для проверки маркировки на фотографии. Читает весь
найденный текст, извлекает номер плавки, напечатанный год и номер листа,
показывает рамки и выровненные вырезки текстовых строк.

## Запуск интерфейса

Из корня проекта (папка с этим README):

```powershell
..\venv\Scripts\python.exe -m metalocr.web_server --config config.final.gpu.json
```

Команда выше использует существующее окружение рядом с папкой проекта.
Если ваше окружение находится внутри проекта, замените путь к Python
на `.\venv\Scripts\python.exe` или `.\.venv\Scripts\python.exe`.

Откройте http://127.0.0.1:8000. Перетащите JPG/PNG или выберите файл,
затем нажмите «Распознать маркировку». Предварительно копировать фотографии
в `images` не нужно. Первый запуск загружает модели в память. На CPU
обработка может занимать несколько минут.

В интерфейсе:

- исходная фотография с пронумерованными рамками найденного текста;
- вырезки строк после выравнивания перспективы, прочитанный текст и уверенность;
- номер плавки, номер листа, год и время обработки;
- сравнение с номерами в имени файла, если их можно извлечь;
- скачивание CSV и подробного JSON.

Имена вида `Труба №19000 Плавка №2023-В203536 Лист №191202000.jpg`
разбираются для сравнения. `19120-2000` из OCR и `191202000` в имени
считаются одним номером листа. Если имя обычное, например `photo.jpg`,
сравнение недоступно, а распознавание работает как обычно.

Имя файла — подсказка, а не проверенный эталон. Оно не передаётся
распознавателю и не подменяет результат. Отсутствующий на фото год не
восстанавливается из имени. Рамки обозначают строки, а не отдельные символы.

Результаты каждого запроса, загруженное фото и вырезки сохраняются в
`results/web/<идентификатор>/`. Они не попадают в Git. Максимум загрузки:
40 МБ и 25 мегапикселей. Сервер слушает только этот компьютер (127.0.0.1).
Остановка — Ctrl+C в терминале. Другой порт: `--port 8001`.

## Запуск из консоли

```powershell
..\venv\Scripts\python.exe recognize.py "C:\photos\photo.jpg" --config config.final.gpu.json --out results
..\venv\Scripts\python.exe recognize.py "C:\photos" --config config.final.gpu.json --out results
```

CSV содержит **ровно пять колонок**, в этом порядке:

```text
file_name,text,heat_id,heat_year,sheet_id
```

`text` — весь распознанный текст; `heat_id` — номер плавки без года;
`heat_year` — год, прочитанный с фото; `sheet_id` — номер листа.
При неизвестном значении поле пустое. CSV записывается в UTF-8 с BOM.
Детали, статусы и ошибки остаются в отдельных JSON, не в дополнительных
колонках CSV. При отсутствии текста или ошибке смотрите JSON или терминал.

## Установка на другом компьютере

Python 3.12, 64 bit. CPU:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m metalocr.web_server --config config.final.cpu.json
```

Для NVIDIA нужна совместимая GPU-сборка PaddlePaddle 3.3.1, установленная
по [инструкции PaddlePaddle](https://www.paddlepaddle.org.cn/install/quick).
После установки GPU-сборки установите остальные зависимости:

```powershell
python -m pip install -r requirements.gpu.txt
python -m metalocr.web_server --config config.final.gpu.json
```

В текущем `requirements.gpu.txt` Paddle GPU закомментирован: он ставится
отдельно. CPU- и GPU-дистрибутивы Paddle устанавливаются в разные окружения.
На Linux вместо Windows-пути используйте `.venv/bin/python`.

Веса обеих моделей включены, около 96 МБ. После установки библиотек
модели не скачиваются. Сохраняйте все три inference-файла каждой модели.
Веса и обучающая выборка не изменялись, переобучение не выполнялось.

## Извлечение листа и ограничения

Поддержаны проверенные форматы:

- `V30593 1282 27` → лист `27`;
- `Z26849 1981 20` → лист `20`;
- отдельная строка `19120-2000` при плавке семейства В → `19120-2000`.

Раздельные OCR-рамки объединяются по геометрии строки. При конфликте
или неподдержанном формате поле листа остаётся пустым; причина есть в JSON.
Уверенность строки OCR не гарантирует правильность номера.

Модель обучена на 405 Train-фото / 1214 кропах, экспортирована 21-я эпоха.
На 76 читаемых Validation-фото: Exact Match номера плавки без года 80,26%,
CER 15,70%, поворот 88,16%, среднее 3,17 с/фото на RTX 3050. Это не
замер всех 436 Test. Чтение всего вспомогательного текста менее точно.
Отдельная точность нового поля sheet_id на всём датасете ещё не измерена.

## Проверки

```powershell
python -m unittest discover -s tests -v
```

Проверяются правила номера листа, отсутствие подстановки из имени,
сравнение, пять колонок CSV, загрузка и скачивание результатов через API,
невалидные файлы и ошибочные запросы. Исходные фото и прошлые результаты
при тестах не изменяются.
